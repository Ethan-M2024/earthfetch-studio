earthfetch Studio
=================

1. Make sure you unzipped this folder (right-click the zip, "Extract All...").
   Then double-click "Start Studio.bat".

   The first time, it sets itself up. That takes a few minutes and needs
   about 400 MB. After that it starts in seconds.

   If "Windows protected your PC" appears, click More info, then Run anyway.
   If Windows asks "Do you want to run this file?", click Run.

2. Your browser opens Studio. If it doesn't, go to:

       http://localhost:7860

3. Keep the black window open while you work. Close it to stop Studio.

Your work is saved in your browser. When you're done, go to step 3 (Send)
in Studio and download the package for your analyst.

Setup trouble? A work VPN or firewall can block the downloads. Try off VPN
or ask IT to allow astral.sh and pypi.org, then run the launcher again.

Help and updates: https://github.com/Ethan-M2024/earthfetch-studio
